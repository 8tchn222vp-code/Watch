# 時間計算機

数字だけで時間を計算できるシンプルなWebアプリです。

## 機能

### ① 時刻の差
- `330` → `500` = 1時間30分

### ② 日をまたぐ時間
- `2300` → `700` = 8時間

### ③ 時間の合計
- `110` + `030` + `050` = 2時間30分

## GitHub Pages

1. GitHubでリポジトリを作成
2. `index.html`をアップロード
3. Settings → Pages
4. Sourceを「Deploy from a branch」
5. Branchを `main`、フォルダを `/ (root)` にして保存
